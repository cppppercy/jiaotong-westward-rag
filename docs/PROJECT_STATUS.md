## 三、程序功能状态

### 资料与索引

- 支持 Markdown、TXT 和文本型 PDF。
- 保留文件名、片段编号、页码或片段位置、原始 URL。
- 资料页显示逐篇正文字符、片段数、大小、解析状态和向量索引状态。
- 支持正文预览、安全删除、上传、重建索引及下载片段清单。
- Streamlit 缓存签名已包含文件状态、切分长度、重叠和 embedding 模型；修改配置后不会错误沿用旧知识库。

### 检索、回答与引用

- Jieba + BM25 与 `BAAI/bge-small-zh-v1.5` 使用相同片段，并可在运行时切换。
- 检索分数预拒答和模型证据充分性判断分别工作。
- 模型只能返回片段编号；程序只接受本次 Top-3 中的真实编号。
- 检索异常、API 异常和正常拒答使用不同状态，不把工程故障算作正确拒答。
- 问答页保留本次会话历史，切换检索方式不清空答案和证据。

### 可信评测

- 检索命中不再按文档名判断，改用 `required_evidence_groups`：所有必要组都必须覆盖，组内允许重叠切分产生的等价片段。
- 已加入三项关键测试：同文档无关片段不命中、多跳只命中一处不完整、所有必要证据齐全才命中。
- 每题结束立即写入检查点；运行中断后可续跑，并能选择只重跑工程错误。
- 每次运行分别导出 BM25 20 条、向量 20 条、合并结果、人工评分表、指标摘要和实验配置。
- 实验配置记录语料摘要、切分参数、Top-K、阈值、模型、提示词版本、运行时间和代码提交号。
- 指标区分评分进度、临时指标和正式指标；正式指标只有在每种方法 20/20 完成、5/5 陷阱题已判定且没有工程错误时生成。
- 人工评分页面逐题展示问题、参考答案、系统答案、必要依据和 Top-3，并可直接保存标注，不必手改大型 JSON。

本地使用 DeepSeek OpenAI 兼容接口；API 密钥只在被 Git 忽略的 `.env` 中。

- 自动化测试：20 项全部通过。
- 正式语料：9 篇、62 片段；62 个片段均带原始 URL。
- BGE 向量维度：512；新语料向量索引已建立并持久化。
- BM25 调试题“西迁精神的主要内涵是什么？”：真实生成成功，2 条引用通过校验。
- 向量调试题“钱学森在交通大学迁校过程中做了什么？”：真实生成成功，2 条引用通过校验。
- 主题相关陷阱调试题“首趟西迁专列一共有多少节车厢？”：即使 BM25 返回高相似片段，模型仍因证据不足正确拒答。
- 调试题只用于运行验证和阈值观察，不进入正式 20 题，也不作为课程指标。

扩充语料后，本机 BM25 阈值已恢复为 1.5，向量阈值保持 0.45。主题相关陷阱题的检索分数与正常题仍可能重叠，因此正式拒答效果必须用本人确定的 5 道陷阱题验证，不能只依赖阈值。

## 七、仍需重点审阅的局限

- 引用白名单只保证片段真实存在，不能自动证明答案每个结论都受证据支持。
- Top-3 对需要多处证据的问题较严格，可能检索不全；正式结果应如实报告。
- BM25 和向量分数不是正确概率，主题相关陷阱题可能得到高分。
- PDF 不包含 OCR，扫描件应先转成文本。
- 网页结构变化可能使采集失败；manifest 中的状态和字数必须在每次获取后检查。
