## 二、已经完成

### 1. 资料处理

- 支持 Markdown、TXT 和包含文本层的 PDF。
- 文档被统一切分为片段，并记录文档名、页码或段落位置、稳定片段编号。
- `data/documents/` 默认不提交，避免公开未经授权的原始资料。
- `data/sources.md` 已整理教育部、西安交通大学新闻网、西迁精神专题网和西迁博物馆等候选来源。

### 2. 检索

- 实现 Jieba 分词与 BM25 关键词检索。
- 实现 `BAAI/bge-small-zh-v1.5` 中文向量检索。
- 两种检索使用相同的文档切分结果，均返回 Top-3、分数和片段信息。
- 向量索引可在本地持久化，并通过语料摘要判断缓存是否仍然有效。

### 3. 回答与引用安全

- 通过 `.env` 使用 OpenAI Chat Completions 兼容接口。
- 提示词要求模型只能根据检索证据回答，证据不足时返回“文档中没有相关信息”。
- 检索最高分低于对应阈值时，系统不调用模型，直接拒答。
- 模型仅返回片段编号；程序只接受本次 Top-3 中存在的编号，并渲染真实文档名、位置和原文。
- 答案为空、没有有效引用或包含越权引用时，系统安全拒答。

### 4. Streamlit 界面

- “知识库问答”：切换 BM25/向量检索，显示答案、引用、Top-3 和完整耗时。
- “资料与索引”：上传资料、查看解析数量、重建向量索引。
- “评测”：下载题集模板、严格校验字段、批量运行两种检索、查看人工标注后的指标。

### 5. 评测工具链

- 提供 20 题 JSON/CSV 模板，预留 10 道资料内题、5 道陷阱题和 5 道多跳题。
- 批量结果包含检索证据、模型回答、引用、拒答状态和耗时。
- 正确性与幻觉字段必须由人工填写，汇总指标只统计已标注记录。
- 当前仅完成工具链，没有声称完成正式评测。

### 6. 工程与文档

- 提供依赖清单、Windows 启动脚本、`.env.example` 和完整 README。
- 提供学习笔记、实验报告、AI 错误记录和视频脚本模板。
- 已有自动化测试覆盖加载切分、检索、回答流程、评测校验和页面冒烟测试。

## 三、本地真实验证记录

本地运行环境使用 DeepSeek 的 OpenAI 兼容接口；密钥仅位于被 Git 忽略的 `.env` 中。

- Streamlit 健康检查返回 HTTP 200，正文为 `ok`。
- 本地官方来源学习提要被解析为 3 个片段。
- BM25 问题“交通大学为什么要西迁？”成功生成回答，并通过 1 条程序化引用校验。
- BGE 向量检索为同类问题返回 3 条结果，最高余弦相似度约为 0.76。
- 向量问题“西迁精神的主要内涵是什么？”成功生成回答，并通过 1 条程序化引用校验。
- BGE 输出向量维度为 512，索引文件能够生成并重新加载。

当前本地知识库较小，BM25 分数尺度与默认示例不同，因此本机 `.env` 临时使用 `BM25_MIN_SCORE=0.04`。该值没有写入公共默认配置；增加正式资料后需要重新校准。

## 七、供检查者重点审阅

- 阈值拒答是否会误拒绝正常问题或放过无关问题。
- 多跳问题在 Top-3 限制下能否同时检索到全部必要证据。
- JSON 输出异常、模型超时和供应商差异下的错误提示是否足够友好。
- 引用白名单只能保证“引用片段真实存在”，不能自动证明答案完全受证据支持；仍需人工核查。
- PDF 当前不包含 OCR，扫描版资料需要先转换为可检索文本。
